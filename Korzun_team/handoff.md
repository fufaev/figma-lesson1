# ♿ Спецификация для разработки (Handoff & Accessibility)

Макет подготовлен к передаче в разработку. Документ фиксирует семантическую структуру будущей HTML-страницы и параметры доступности интерфейса.

## 1. Семантическая иерархия заголовков

*   `<header>` — логотип «ДВИЖ», навигация `<nav>` (якоря `#directions`, `#pricing`, `#teachers`, `#contacts`), телефон.
*   `<h1>` — НАУЧИСЬ КРУТО ТАНЦЕВАТЬ *(первый экран, один на странице)*
*   `<h2>` — ПОЧЕМУ МЫ *(Advantages)*
    *   `<h3>` — названия 4 преимуществ
*   `<h2>` — НАПРАВЛЕНИЯ *(Directions)*
    *   `<h3>` — название выбранного направления (Хип-хоп)
*   `<h2>` — СТОИМОСТЬ ЗАНЯТИЙ *(Pricing)*
    *   `<h3>` — названия тарифов; `<h3>` — заголовок формы «Пробное занятие бесплатно»
*   `<h2>` — ПЕДАГОГИ *(Teachers)*
    *   `<h3>` — имена педагогов
*   `<h2>` — КОНТАКТЫ *(Contacts)*
*   `<footer>` — логотип, дублирующая навигация, копирайт.

Уровни заголовков не пропускаются (после h1 идёт h2, после h2 — h3). Вкладки направлений — `<button>` с `aria-selected`, поля формы — `<input>` с видимыми `<label>`.

## 2. Альтернативные тексты (`alt`) для изображений
Декоративные элементы (оранжевые штрихи, фоновые пятна) реализуются через CSS-background или получают `alt=""`.

| Слой в Figma | Файл ассета | Текст `alt` |
|---|---|---|
| `Hero/Background` | `photo.jpg` | «Группа учеников танцует на занятии в светлом зале студии» |
| `Directions/Card/Image` | `hiphop.jpg` | «Танцоры в спортивной одежде исполняют хип-хоп-связку в зале» |
| `Teacher-card/Photo` (1–4) | `1.png`–`4.png` | «Педагог Алина Мельник, хип-хоп и хилс» (и аналогично для каждого педагога — имя и направление) |
| `Contacts/Map` | `map.jpg` | «Схема проезда к студии танцев „ДВИЖ“, ул. Условная, 1» |
| Иконки `phone`, `telegram`, `instagram` | SVG | Пустой `alt=""` + `aria-label` у ссылки («Позвонить», «Написать в Telegram») |

## 3. Контрастность текста (WebAIM Contrast Checker)
Проверка по WCAG 2.1, порог AA: обычный текст — `4.5:1`, крупный (от 24px или 18.66px bold) — `3:1`.

| Сочетание | Текст | Фон | Результат | Статус |
|---|---|---|---|---|
| Основной текст на белом | `#111111` | `#FFFFFF` | **18.88:1** | AA / AAA ✅ |
| Заголовки и текст на синем | `#FFFFFF` | `#2D4BD6` | **6.8:1** | AA ✅ |
| Текст на оранжевой кнопке (Default) | `#111111` | `#FFA800` | **9.76:1** | AA / AAA ✅ |
| Текст на кнопке Hover | `#FFFFFF` | `#2D4BD6` | **6.8:1** | AA ✅ |
| Белый текст в Footer | `#FFFFFF` | `#111111` | **18.88:1** | AA / AAA ✅ |

**Отклонённые варианты:** белый текст на оранжевом `#FFA800` (как в референсе) — **1.93:1, не проходит**; поэтому на оранжевых кнопках текст тёмный. Синий референса `#416CE0` с белым текстом — 4.72:1, проходит с минимальным запасом, поэтому основной синий затемнён до `#2D4BD6`. Оранжевый `#FFA800` на синем `#2D4BD6` (3.51:1) используется только для крупных декоративных элементов, не для мелкого текста.

## 4. Рекомендуемые форматы графического экспорта
*   **Векторные иконки (телефон, мессенджеры, стрелки, иконки преимуществ):** `SVG`.
*   **Фотографии (Hero, направления, педагоги):** `WebP` (запасной `JPG`), в 1x и 2x для Retina.
*   **Карта:** `WebP`; на реальном сайте — встраиваемая карта OpenStreetMap с атрибуцией.
