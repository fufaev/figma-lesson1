## ✨ Бонус: альтернативная палитра «Glam»

Дополнительно к основному макету сделали эскиз той же страницы в чёрно-розовом стиле с леопардовым декором. Он лежит на странице `Desktop` рядом с основным фреймом (`Bonus — Glam concept`), экспорт — `exports/desktop-glam.png`. Сдаём основной (синий) вариант, этот — эксперимент с персонализацией.

| Роль | HEX | Контраст |
|---|---|---|
| Фон секций | `#0D0D0D` | белый текст 19.44:1 ✅ |
| Акцент, кнопки | `#FF2E93` | чёрный текст 5.45:1 ✅, белый 3.46:1 ❌ |
| Цены и ссылки на белом | `#D6006F` | 5.14:1 ✅ |
| Фон карточек | `#FFD6EA` | тёмный текст 14.44:1 ✅ |

На розовых кнопках текст чёрный, потому что белый не проходит WCAG AA. Леопардовый принт нарисован векторно и используется только как декор (`alt=""`), под текстом его нет. В эскизе цвета заданы вручную, без отдельных стилей; для полноценной второй темы нужны Variables с двумя режимами.
