# 🏗️ Спецификация раскладки и стресс-тестирования (Components & Адаптивность)

Документ описывает техническую сторону макета: логику Auto Layout, поведение адаптивной сетки на трех брейкпоинтах и результаты прохождения стресс-теста на переполнение контентом.

## 1. Архитектура Auto Layout (Flexbox-модель)
Все контейнеры макета спроектированы без жестко заданной высоты, опираясь на свойства Auto Layout (аналог CSS Flexbox):
*   **Навигационный Header:** `Direction: Horizontal`. Настройки выравнивания элементов по вертикали (`Align: Center`). На Tablet и Mobile версиях элементы перестроены, кнопка меню скрыта под иконку «бургер».
*   **Секция «Преимущества» (Сетка карточек):** Использован режим `Auto Layout: Wrap` (Flex-wrap). На Desktop карточки выстраиваются в ряд, на Tablet автоматически переносятся по две в ряд, на Mobile вытягиваются в один вертикальный стек.
*   **Форма записи:** Собрана на базе вертикального Auto Layout (`Direction: Vertical`) с фиксированным шагом `Gap: XXpx` между полями ввода.

## 2. Адаптивная трансформация (Desktop / Tablet / Mobile)
Перенос и масштабирование контента между тремя целевыми фреймами:
*   **Desktop (1440px):** 12-колоночная сетка, контент по центру (ограничение ~1200px), максимальные отступы и размеры шрифтов.
*   **Tablet (768px):** Переход на 6-колоночную сетку, уменьшение внутренних padding до `XXpx`, скрытие второстепенных декоративных элементов (векторных брызг).
*   **Mobile (390px):** 4-колоночная сетка, шрифты уменьшены на 15-20%, все горизонтальные структуры перестроены в вертикальные (`Direction: Vertical`).

## 3. Отчёт по стресс-тестированию текстовых блоков
Для проверки надежности верстки в гибкий текстовый блок описания тренажерного зала (или карточки тренера) на Mobile-фрейме было искусственно добавлено ~100 слов связного текста.

*   **Ожидаемое поведение (Критерий успешности):** Контейнер должен динамически растянуться вниз, автоматически отодвинув нижние элементы (секции/кнопки) за счет Auto Layout. Наложения слоев или вылетов текста за границы фрейма быть не должно.
*   **Результат:** Тест пройден успешно. Настройки родительских контейнеров `Height: Hug contents` отработали корректно. Сравнительные скриншоты зафиксированы в файлах `exports/stress-test-before.png` и `exports/stress-test-after.png`.
